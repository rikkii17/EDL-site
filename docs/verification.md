# 実装と検証の記録

2026年10月7日。EDLは`ex-web`、サイトは`dev`で作業。
本番サーバー、DNS、ファイアウォールの変更やデプロイは行っていない。

## 既存コードの維持

EDLのメイン処理を元の構成に戻し、初期化、Serialログ、測定、評価、GPIO表示、
起動時の表示テストを保持した。既存処理の変更は、通信呼び出しの追加と、
受信失敗・CRC不一致・校正状態判定・無期限再試行・符号なし計算などの不具合修正。
温湿度の換算式、騒音の電圧換算式、評価基準と騒音の丸め処理は引き継いだ。
既存のworkspace設定変更はコミットしていない。

サイトは既存React/TypeScript/Vite構成と、開始時点の空のAppを土台に実装した。
測定表示、履歴、管理設定、通信処理を個別のコンポーネント・フックに分離。
追加コードの説明コメントは日本語。

## ビルド・検証結果

- UNO R4 WiFiの`main`ビルド成功。RAM 7,168/32,768バイト、Flash 69,308/262,144バイト。
- ネイティブC++検証成功。実際のJSON生成処理、非有限値、欠測、バッファ上限、
  評価の境界値、模擬I2CのCRC・短い受信・NACK・busy・未校正・ENS160暖機を検証。
- サイトのTypeScript/Viteビルド、ESLint、PHP構文検査が成功。
- 本番依存関係の`npm audit --omit=dev`で既知の脆弱性報告は0件。
- PHPの実HTTPセキュリティ検証13ケースが成功。送信キー、管理認証、CSRF、
  セッション更新・期限・ログアウト、入力型と範囲、本文上限、履歴取得範囲、
  アクセス頻度制限、転送元ヘッダーの偽装、HTTPS必須、公開領域への秘密配置拒否、
  ロック待ち制限、失敗時の情報非公開、セッション生成上限・期限切れ掃除、
  破損した頻度制限ファイルの拒否を検証。
- 実際のC++出力からPHP受信API、最新値、集計、日別JSONL、履歴APIへの結合検証成功。
  欠測を平均に含めないこと、cron再実行で重複しないこと、設定変更が次の集計から
  適用されることも検証した。
- スマホ幅390pxのブラウザで、最新値・履歴・管理ログイン・保存間隔変更・ログアウトを
  確認。横方向のはみ出しなし。

## 配置後に確認すること

実機ArduinoのWi-Fi接続、実センサーの測定、公開ドメインのTLS接続は未検証。
PHPのローカルHTTP検証はPHP 8.4で実行し、実装はサーバーのPHP 8.1で使える構文に限定。
Ubuntu上のApache設定は配置先で`apache2ctl configtest`を実行し、有効モジュールを確認する。
静的ページへの連打対策はmod_evasiveの導入・有効化が必要で、API内の制限とは別。
Apacheと実ネットワークでの攻撃耐性・最大接続数は、本番を操作していないため未実測。

IP制限は同じ学校・モバイル回線の利用者が共有し、固定バケットの衝突でも巻き込まれる
場合がある。単一サーバーで帯域を埋める大規模攻撃への防御は保証しない。
保存はファイル方式なのでDBのトランザクションと同等ではなく、電源断などへの
バックアップ・復旧運用は配置先で必要。

デプロイの手順と秘密情報の生成は、リポジトリ直下の`README.md`を参照。
